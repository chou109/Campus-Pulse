## 2.1 微信 WXML 编译错误修复

微信开发者工具提示 `pages/challenges/challenges.wxml` 中存在 `unexpected token .`。原因是 WXML 表达式不支持直接调用 `toFixed()` 方法：

```wxml
{{(item.progress*100).toFixed(0)}}
```

已改为在 `pages/challenges/challenges.js` 中预先计算：

- `progressText`：用于显示百分比；
- `progressWidth`：用于进度条宽度。

WXML 现在只读取字段，不再调用 JavaScript 方法。当前项目配置中的测试号 AppID 已确认是 `wxe9d70045c1937d39`。

## 2.3 地图折线渲染错误修复

开发者工具报告 `MultiPolyline.geometries` 的 `paths` 无效，并伴随 `Invalid typed array length: -3`。本轮将运动页地图更新改为：

- 第一个有效定位点只更新地图中心，不创建折线；
- 至少有两个有效点后才传入 `polyline`；
- 对经纬度进行数字和有限值校验；
- 暂不传入不完整的 marker 对象，避免缺少图标资源造成额外渲染错误。

地图 `polyline` 仍使用小程序地图组件要求的 `points: [{ latitude, longitude }]` 结构；该结构用于从坐标数组首尾连线。
