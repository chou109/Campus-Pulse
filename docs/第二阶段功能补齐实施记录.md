## 6. 本轮继续扩展

### 趋势、统计与运动记录

- 首页支持周趋势/月趋势切换；
- 周图按周一至周日真实聚合，月图按自然月周段聚合；
- 周里程、月里程、周目标进度、与上周变化均由本地记录计算；
- 清空记录后应用重启仍保持空记录，不再错误恢复默认示例；
- 运动记录列表按时间倒序，详情页支持有效轨迹过滤和轨迹空态；
- 打卡预览卡片、复制打卡文案和小程序邀请分享受“允许好友看到打卡”设置约束；
- 分享入口不暴露原始轨迹，也不使用接收端无法读取的本地记录详情路由。

### 挑战与社交展示

- 新增挑战详情页，展示目标、周期、规则、参与人数演示值和本机进度；
- 挑战列表和推荐卡片可进入详情；
- 挑战加入、退出维持本地状态；
- 新增规则型挑战推荐解释，根据本机运动数据和连续天数生成，不调用大模型；
- 榜单中的本人周/月里程由本机记录计算；其他同学仍为演示数据，并在页面明确说明；
- 关闭周榜公开时，本人昵称、头像、学院和里程均不展示。

### 运动记录安全和反馈

- 运动计时防止重复结束确认；
- 仅在存在至少两个有效轨迹点且里程达到最低阈值时允许结束运动；
- 校验定位经纬度范围、精度和跳点；
- 定位异步回调绑定运动 session，停止/卸载后不会回写旧页面；
- 演示模式不再显示系统当前位置；
- 运动数据读取时清洗非法日期、非有限数值和无效轨迹点；
- 新增本地反馈草稿页，可编辑、复制和清空；反馈不自动上传。

### 研究原型说明

- 运动提醒设置明确标注为本地偏好，不会发送订阅消息；
- 热门活动参与人数、同学排行榜和奖励均标注为演示内容；
- README 增加自动化测试命令和新增页面说明；
- AI 应用仍暂缓：没有模型 API、AI 页面、云函数、API Key 或后端接入。

## 9. AI 运动复盘 API 测试接入

根据 Owner 新授权，增加本机开发代理与运动详情页 AI 复盘入口：

- `dev/ai-proxy.js`：Node 内置模块实现，仅监听 `127.0.0.1`；从进程环境读取 Key；仅转发六个聚合数字/配速字段；限制请求体、请求超时、输入范围和输出 schema；

- `pages/record-detail/`：用户主动点击按钮后才发起复盘；明示只发送聚合数据、不发送轨迹和身份信息；标注非医疗建议。

真实网关连通性已验证：

- `GET /v1/models` 返回可用模型列表；
- 使用合成运动统计向 `/v1/chat/completions` 请求 `gpt-5.5`，HTTP 200 并返回符合字段约定的中文 JSON 复盘；
- 未将 API Key 写入仓库、配置文件、README、测试样例或小程序包；
- 网关代理转发、隐私字段白名单、无 Key 错误、无效输入、模型失败降级均由自动化测试覆盖。

**凭据安全：** API Key 曾在对话中明文出现，建议在网关管理界面撤销旧 Key 并生成新 Key。按 README 的终端交互方式在本机输入新 Key 后运行 `node dev/ai-proxy.js`；不要把 Key 写进文件或再次发到聊天。

真机和生产环境仍不使用 localhost 代理；模型 Key 需在本机终端环境配置，不进入仓库。
